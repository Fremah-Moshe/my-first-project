# my-first-project
Task 1: Install and verify the four core tools
What to do:

Install Visual Studio Code from code.visualstudio.com. During install, tick "Add to PATH" if the installer offers it.
Open VS Code and install these four extensions from the Extensions panel (not from AI): Prettier, ESLint, Live Server, Tailwind CSS IntelliSense.
Install Git from git-scm.com.
Install Node.js LTS from nodejs.org.
Open a terminal (macOS: Terminal; Windows: Git Bash; Linux: your usual terminal) and run each of these commands, writing down the version number you see:
code --version
git --version
node --version
npm --version

Task 2: Configure Git with your identity
What to do: Run these two commands in your terminal, substituting your own name and email. Use the same email you will use for GitHub in Task 3.

Task 3: Create a GitHub account and your first repository
What to do:

Sign up for a free GitHub account at github.com if you do not already have one. Use a professional username -- this will appear on your CV and your pull requests for years.
From your GitHub profile, create a new public repository named my-first-project. Tick "Add a README file".
