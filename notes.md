# VS Code  
VS Code is your coding workspace — the place where you write, edit, and organize all your project files. 
It gives you helpful features like syntax highlighting, extensions, and debugging tools so you’re not coding blind. 
You install it because you need a proper environment to build and manage your projects.

# Git  
Git is your project’s history system — it records every change you make so you can go back, compare versions, or undo mistakes. 
It also lets you collaborate with others without overwriting each other’s work. 
You install it because modern development depends on version control and pushing code to platforms like GitHub.

# Node.js  
Node.js is the engine that lets JavaScript run on your computer instead of only inside a browser. 
It also comes with npm, which is how you install libraries and tools used in almost every modern web project. 
You install Node because frameworks, build tools, and development servers all rely on it.

# Terminal  
The terminal is a text-based control panel where you type commands to interact with your computer directly. 
It’s how you run Git commands, start Node programs, install packages, and manage your project behind the scenes.
You install or use a terminal because many developer tools don’t have buttons — they only work through commands.
